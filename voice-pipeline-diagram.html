State Machine
BookingStateInjector Deterministic
This is the brain. Imported from fonely.voice.dialogue.BookingCollection — the gated code, not a copy.
1. Parse date "இன்னைக்கு" → today, "நாளைக்கு" → tomorrow. Tamil numerals: ஐந்து=5, பத்து=10
2. Parse time "12 மணிக்கு" → 12:00, "5 pm" → 17:00. Matches against offered slots only.
3. Track fields Owns the order: reason → date → time → name → confirmation. LLM cannot skip or reorder.
4. Detect confirmation "yeah", "ok", "ஆமா", "sari" all recognized. Code-enforced, not prompt-dependent.
active: true
reason: toothache
target_date: 2026-08-10
selected_time: 17:00

required_field: name ← LLM must ask THIS
LLM
GPT-5.6 Luna LLM
Receives the caller's text + booking state. Sees required_field: name and generates a natural Tamil response asking for the name. It phrases the question — it does not choose which question.
Output: "உங்க பேரு சொல்லுங்க?"
Safety Gates
BookingPostLLMGate Gate
Four deterministic checks on every LLM response before it reaches the caller.
Gate 1: Medical advice If LLM says "root canal தேவை" → replaced with "Doctor பார்த்துதான் சொல்வாங்க"
Gate 2: Confirmation loop If caller said "yeah" → force "Booking note பண்ணிட்டேன்" — never repeat readback
Gate 3: Conversation closure If caller said "bye" after booking → force "நன்றி, take care!"
Gate 4: Forced readback If all 4 fields collected but LLM skipped readback → inject deterministic readback
Text → Speech
Cartesia TTS External
Kavitha Tamil voice, sonic-3.5. Converts the approved text to natural Tamil audio at 24kHz.
Caller hears
🔊 Voice Response
Only text that passed all 4 gates reaches the caller's ear. Medical advice, confirmation loops, and false bookings are physically impossible.
